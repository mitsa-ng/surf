# Surf 瀏覽器 — Milestone 1：全骨架＋可執行垂直切片

## Context
`/Users/mac/Desktop/Surf` 為空目錄，使用者提供四層架構圖（UI / Rust core / Web view / Tauri shell）。已定案：
- **範圍**：完整 Cargo workspace 骨架（全部 crate 可編譯）＋桌面垂直切片（tab strip + address bar + WKWebView 實際載入網頁）
- **UI**：Svelte 5；design direction 由使用者提供：**安静極簡／跟隨系統 light-dark／灰階＋海藍 accent／系統字＋舒適密度**（原封記入 DESIGN.md）
- **平台**：桌面＋移動端都是 day-1 target；macOS 今天可跑，Android/iOS 完成 scaffold（NDK 缺失需補裝）
- **antislop**：DURING mode（session override），實作時套用 antislop-ui + antislop-layoutmobile
- 已查證：Tauri v2 單窗口 multiwebview 僅桌面；行動端 tab 採 instance-swap。rquickjs 活躍維護（2026-09）。WKContentRuleList 僅支援 block 類規則（無 header rewrite）。

## 實作步驟
1. **Bootstrap**：`git init`；撰寫 NOTES.md（隨做隨寫）、DESIGN.md（使用者答案逐字）、AGENTS.md、root scripts。
2. **surf-core**：urlbox（omnibox heuristics，unit test）、rusqlite storage＋migrations、tab model；suspension/crypto/sync 為 trait＋stub。
3. **surf-ext-host**：manifest 型別＋loader/registry、permission grants、match-pattern 引擎（真實實作＋test）、rules（adblock-rust wrapper＋declarative types＋capability flags）、rquickjs runtime（每擴充一個 context）、message router（typed envelopes＋test）、ApiHost trait＋stubs。
4. **Tauri app**：layout manager（desktop chrome 在頂、mobile 在底，resize 重排）、tab manager（create/hide/show webview）、commands（tab_open/close/activate/navigate/back/forward/reload）＋events；Rust core 為狀態真相，UI 靠 event mirror。RequestFilter trait＋macOS capability report。
5. **Svelte UI**：desktop（TabStrip＋AddressBar＋nav）與 mobile（BottomBar＋tab sheet）兩種 deliberate layout；ipc.ts typed；design tokens 依 DESIGN.md（accent 只在關鍵時刻）。
6. **Mobile**：sdkmanager 裝 NDK → `tauri android init` → `tauri ios init`；紀錄 build 指令；模擬器煙霧測試（若可用）。
7. **驗證**：cargo test/clippy、vitest、`tauri dev` 實測瀏覽、Android assembleDebug；最後派 fresh-context subagent 獨立核對架構符合度（全域規則 2）。
